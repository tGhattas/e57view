    Undo/redo cover crop and AI clean. Save as… writes a copy of the current points to a file you choose, updates the on-device cache if there is one, and clears undo. ⌘Z / ⇧⌘Z / ⌘S. Escape cancels a crop region.

    Crop

    Drag the arrows to move, the rings to rotate, the handles to resize. Double-click a point to move the orbit centre, then centre the region there. Points outside every keep region are dimmed in preview. Escape cancels the region.

    Sections

    Keep only what lies inside any section. Each is a slab you move, tilt and thicken with the gizmo — floors, a wall, a corridor.

Sessions are read-only and expire after 8 hours; tick Allow edits to let an agent crop, clean, save or call a paid model. Keep this tab open.
