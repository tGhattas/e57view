    Undo/redo cover crop and section edits. Save as… writes a copy of the current points to a file you choose, updates the on-device cache if there is one, and clears undo. ⌘Z / ⇧⌘Z / ⌘S. Escape cancels a crop region.

    —

    Crop

    Drag the arrows to move, the rings to rotate, the handles to resize. Double-click a point to move the orbit centre, then centre the region there. Points outside every keep region are dimmed in preview. Escape cancels the region.

    —

    Sections

    Keep only what lies inside any section. Each is a slab you move, tilt and thicken with the gizmo — floors, a wall, a corridor.

      Analysis

      NORMALS

      Surface reconstruction and shading both need normals. Compute fits a plane to each neighbourhood; Orient makes neighbours agree and turns them outward.

      CLUSTER AND THIN

      Components labels groups of points that touch within the spacing. Thin keeps one point per cube of that size.

      —

      Scalar field

      no field

      A field is one number per point. Colour by it with Colour → Scalar field, narrow the display range to see detail, or filter to keep only part of the cloud.

      Surface

      —

      Builds a triangle surface from the points and their normals. Detail is the voxel size: smaller is finer and slower, and below the scanner's own point spacing it only adds noise. Fill gaps widens the band each point writes, closing small holes at the cost of rounding sharp edges.

      Agent

      off

      Lets an agent on this machine drive the viewer through the e57view MCP server. It is one file and needs only Node 20; a web page cannot start it for you, so download it and register it once:

      curl -fsSL https://opensketch.web.app/mcp.mjs -o e57view-mcp.mjs
claude mcp add e57view -- node "$PWD/e57view-mcp.mjs"

      Then tick Local MCP above. The server listens on 127.0.0.1 only, so nothing is exposed off this machine; Chrome asks once to allow local network access.

      —

      Copies a page link plus a bearer token for POST /agent, so an agent can drive this tab from anywhere without MCP. The token is shown once and never appears in the URL. A session dies when you close this tab, and expires after 8 hours; tick Allow edits to let an agent crop, delete or save. Keep this tab open.
